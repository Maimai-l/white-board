局域网共享白板 · 使用说明
================================

准备
----
Mac 上需要有 Python 3.10 或更高版本（终端里执行 python3 --version 可以确认，
没有的话去 https://www.python.org/downloads/ 装一个）。
Mac 和 iPad 连同一个 Wi-Fi。

安装（推荐）
------------
到仓库的 Releases 页面下载 Whiteboard-*-macos-arm64.zip（Intel 机器选 x86_64），
解压后把 Whiteboard.app 拖进「应用程序」，像普通应用一样双击打开。

第一次打开会有两个系统提示：
  1. 「无法验证开发者」→ 右键点应用 → 打开 → 再点「打开」。只需这一次。
  2. 「想要查找并连接到本地网络上的设备」→ 必须允许，否则 iPad 连不上。

以后不用手动更新：应用会自己查新版本，界面上方会出现提示，点一下就更新并重启。

从源码跑（可选）
----------------
  git clone https://github.com/Maimai-l/white-board.git
然后双击 start-whiteboard.command；更新双击 update.command。
脚本被系统拦住时同样是右键 → 打开。

把白板装到 iPad 主屏
--------------------
1. Mac 窗口右上角点最后一个图标（iPad 形状），卡片上有地址，
   形如 http://你的电脑名.local:8848/
2. 点卡片上的下载按钮保存描述文件，用隔空投送发给 iPad；
   或者直接让 iPad 的 Safari 打开 http://你的电脑名.local:8848/profile.mobileconfig
3. iPad：设置 → 已下载描述文件 → 安装（会提示「未签名」，确认即可）
4. 主屏出现「白板」图标，点开就是全屏白板。

日常使用
--------
iPad：底部工具栏是钢笔、马克笔、荧光笔、橡皮擦、手指书写开关、颜色粗细、撤销、清屏。
      默认只有 Apple Pencil 能画线，手指负责平移和缩放，手掌搭上去不会留痕。
      没有 Pencil 时，点亮工具栏上的手形图标就能用手指写（单指书写、双指平移缩放）。
Mac： 鼠标左键书写，空格 / 中键拖动画布，滚轮平移，⌘ + 滚轮缩放，⌘Z 撤销。
      右上角依次是：白板选择、白板设置（背景 / 存储目录）、导出 PNG、iPad 连接。
      新建白板时选延伸方式：四向无限的大白板，或宽度固定、只向下延伸的笔记。
      右下角中间的按钮是「回到内容」。

白板内容自动保存在
  ~/Library/Application Support/Whiteboard/boards-data
可以在「白板设置」里改到别的文件夹。

不开程序窗口、只想用浏览器访问时，双击 browser-mode.command。

出问题
------
终端窗口里的报错信息直接反馈即可。常见情况：
  * iPad 打不开地址 —— 确认两台设备在同一个 Wi-Fi，且 Mac 上程序正在运行。
  * 端口被占用 —— 程序会自动往后顺延，地址里的端口号以窗口里显示的为准。
