LAN Shared Whiteboard - Getting Started
=======================================

Requirements
------------
- A Mac with Apple silicon, and an iPad.
- The Mac and the iPad are on the same Wi-Fi network.
- Running from source only: Python 3.10 or later on the Mac.
  Check with: python3 --version
  Download: https://www.python.org/downloads/

Install (recommended)
---------------------
1. On the repository's Releases page, download Whiteboard-<version>-macos-arm64.zip.
2. Unzip it and drag Whiteboard.app into "应用程序" (Applications).
3. Open it by double-clicking.

On first launch, macOS shows two prompts:
  1. The developer cannot be verified: right-click the app, choose Open,
     then click Open again. This is required only once.
  2. "想要查找并连接到本地网络上的设备" (find and connect to devices on your
     local network): click Allow. Without it, the iPad cannot connect.

Updates
-------
The app checks for a new version at launch. When one is available, an update
dialog shows the release notes and three choices:
  - "跳过这个版本" (Skip this version): no further prompts for this version.
  - "退出应用时安装" (Install on quit): the update is installed when the app quits.
  - "安装并重启应用" (Install and restart): the update is installed now and
    the app reopens.
The switch "以后自动下载更新" (Download updates automatically) is off by
default. When it is on, the update is downloaded in the background before
the dialog appears.
To check manually: "关于" (About), the last icon at the top right, then
"检查更新" (Check for updates).

Run from source (optional)
--------------------------
  git clone https://github.com/Maimai-l/white-board.git
- start-whiteboard.command: starts the app. The first run installs the
  dependencies.
- update.command: updates to the latest version (git pull).
- browser-mode.command: runs the server without a window. Open the board in
  a browser.
If macOS blocks a script, right-click it and choose Open.

Add the board to the iPad Home Screen
-------------------------------------
1. In the Mac window, click the iPad icon at the top right ("连接 iPad",
   Connect iPad). The card shows the address, for example
   http://<computer-name>.local:8848/
2. Click the download button on the card and send the profile to the iPad
   with AirDrop. Alternatively, open this address in Safari on the iPad:
   http://<computer-name>.local:8848/profile.mobileconfig
3. On the iPad: Settings > Profile Downloaded > Install. The profile is
   unsigned; confirm the installation.
4. The "白板" (Whiteboard) icon appears on the Home Screen and opens the board
   full screen.

Daily use
---------
iPad:
  - The toolbar is the tool picker (PencilKit style): undo, redo, pen,
    marker, highlighter, eraser, and colors. Tap the selected tool to change
    its width. Drag the tool picker to another edge or corner.
  - "更多" (More) in the tool picker contains auto-minimize, finger drawing,
    and clear board.
  - By default only the Apple Pencil draws. One finger pans, two fingers
    zoom, and a resting palm leaves no mark.
  - Without an Apple Pencil, turn on finger drawing: one finger draws, and
    two fingers pan and zoom.
  - By default the iPad and other devices can only draw. To allow managing,
    setting up, clearing, or exporting boards, turn on the matching
    permission in "白板设置" (Board settings) on the Mac.
Mac and other devices (classic toolbar):
  - The toolbar contains pen, marker, highlighter, eraser, color and width,
    undo, redo, and clear board. On touch devices it also contains the
    finger drawing switch.
  - Mouse: the left button draws. Space + drag or the middle button pans.
    The scroll wheel pans. Cmd + scroll wheel zooms.
  - Keys: Cmd+Z undo, Cmd+Shift+Z redo, Cmd+= / Cmd+- zoom, Cmd+0 fit content.
  - Top right, in order: board chooser, "白板设置" (Board settings:
    background, storage directory, permissions), export PNG, connect iPad,
    and about. Connect iPad and about appear only in the Mac window.
  - Bottom right: zoom in, "回到内容" (Fit content), zoom out.
  - New board: choose an infinite board (extends in all four directions) or
    a note board (fixed width, extends downward). Drag a PDF or an image into
    the window to create a document board.

Storage
-------
Boards are saved automatically to:
  ~/Library/Application Support/Whiteboard/boards-data
Change the storage directory in "白板设置" (Board settings).

Troubleshooting
---------------
Report problems together with the log file ~/Library/Logs/Whiteboard.log
(when running from source, the Terminal window output).
  * The iPad cannot open the address: check that both devices are on the same
    Wi-Fi network and that the app is running on the Mac.
  * The port is in use: the app tries the following ports (8849, 8850, and so
    on, up to 20 attempts). Use the port shown in the Mac window.
