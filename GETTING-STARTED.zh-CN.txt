局域网共享白板 · 快速入门
=========================

准备
----
- 一台 Apple 芯片的 Mac，以及一台 iPad。
- Mac 与 iPad 连接同一个 Wi-Fi 网络。
- 仅从源码运行时需要：Mac 上安装 Python 3.10 或更高版本。
  确认方法：python3 --version
  下载地址：https://www.python.org/downloads/

安装（推荐）
------------
1. 在仓库的 Releases 页面下载 Whiteboard-<版本号>-macos-arm64.zip。
2. 解压后将 Whiteboard.app 拖入「应用程序」。
3. 双击打开。

首次打开时，macOS 显示两个提示：
  1. 无法验证开发者：右键点按应用，选择「打开」，再点按「打开」。
     此操作只需进行一次。
  2. 「想要查找并连接到本地网络上的设备」：点按「允许」。
     不允许时，iPad 无法连接。

更新
----
应用在启动时检查新版本。有新版本时，更新对话框显示更新说明与三个选项：
  - 「跳过这个版本」：此版本不再提示。
  - 「退出应用时安装」：退出应用时安装更新。
  - 「安装并重启应用」：立即安装更新并重新打开应用。
「以后自动下载更新」开关默认关闭。打开后，更新会在对话框出现之前于后台
下载完毕。
手动检查：点按右上角最后一个图标「关于」，再点按「检查更新」。

从源码运行（可选）
------------------
  git clone https://github.com/Maimai-l/white-board.git
- start-whiteboard.command：启动应用。首次运行时安装依赖。
- update.command：更新到最新版本（git pull）。
- browser-mode.command：不打开窗口，只运行服务，用浏览器访问白板。
脚本被 macOS 阻止时，右键点按脚本并选择「打开」。

将白板添加到 iPad 主屏幕
------------------------
1. 在 Mac 窗口中点按右上角的 iPad 图标（「连接 iPad」）。卡片上显示地址，
   例如 http://<电脑名>.local:8848/
2. 点按卡片上的下载按钮，将描述文件通过隔空投送发送到 iPad；
   也可以在 iPad 的 Safari 中打开：
   http://<电脑名>.local:8848/profile.mobileconfig
3. 在 iPad 上：设置 > 已下载描述文件 > 安装。描述文件未签名，确认安装即可。
4. 主屏幕上出现「白板」图标，点按后以全屏方式打开白板。

日常使用
--------
iPad：
  - 工具栏为笔具盘（PencilKit 样式）：撤销、重做、钢笔、马克笔、荧光笔、
    橡皮擦与颜色。点按当前选中的工具可调整粗细。笔具盘可拖动到其他边或角。
  - 笔具盘的「更多」中包含自动最小化、手指书写与清空白板。
  - 默认只有 Apple Pencil 可以书写。单指平移，双指缩放，手掌放在屏幕上
    不留痕迹。
  - 没有 Apple Pencil 时，打开手指书写：单指书写，双指平移与缩放。
  - iPad 与其他设备默认只能书写。如需允许管理、设置、清空或导出白板，
    在 Mac 的「白板设置」中打开对应权限。
Mac 与其他设备（普通工具栏）：
  - 工具栏包含钢笔、马克笔、荧光笔、橡皮擦、颜色与粗细、撤销、重做与
    清空白板。触摸设备上另有手指书写开关。
  - 鼠标：左键书写；按住空格拖动或按住中键拖动可平移；滚轮平移；
    Cmd + 滚轮缩放。
  - 快捷键：Cmd+Z 撤销，Cmd+Shift+Z 重做，Cmd+= / Cmd+- 缩放，
    Cmd+0 回到内容。
  - 右上角依次为：白板选择界面、「白板设置」（背景、存储目录、权限）、
    导出 PNG、连接 iPad、关于。连接 iPad 与关于只在 Mac 窗口中出现。
  - 右下角：放大、「回到内容」、缩小。
  - 新建白板时选择大白板（向四个方向无限延伸）或笔记（宽度固定，
    向下延伸）。将 PDF 或图片拖入窗口可新建文档板。

存储
----
白板自动保存到：
  ~/Library/Application Support/Whiteboard/boards-data
可在「白板设置」中更改存储目录。

问题排查
--------
反馈问题时请附上日志文件 ~/Library/Logs/Whiteboard.log
（从源码运行时，附上终端窗口中的输出）。
  * iPad 无法打开地址：确认两台设备连接同一个 Wi-Fi 网络，且 Mac 上的
    应用正在运行。
  * 端口被占用：应用依次尝试后续端口（8849、8850 等，最多尝试 20 个）。
    以 Mac 窗口中显示的端口为准。
