# 界面文字

界面上的每一处文字都按这里写：按钮、标签、提示（title）、aria-label、占位文字、消息条、
对话框，以及发给用户看的 HTML 页面（速写页、iPad 外壳安装页、启动失败的窗口）。
写法参照 macOS 自带应用。`tests/test_ui_text.py` 扫描页面脚本和 HTML，发现不允许的符号就失败。

日志不算界面文字：`reportError(…)`、`console.*(…)`、Python 的 `log.*(…)` 和抛给开发者的
异常可以照常写中文标点。

## 规则

1. **不用全角括号和引号。** 「」『』《》（）一律不出现。文字里不给控件名加引号；
   一句话非要提到某个控件，就换一种说法。
2. **冒号后面不接细节。** 出错时界面上只说出了什么事，原因写进日志
   （网页用 `reportError`，Python 用 `log`），不能悄悄吞掉。
3. **短文字是一个短语，不加标点。** 按钮、标签、提示、消息条、占位文字里没有 ，。？！：、。
   例外：进行中的文字以省略号结尾（正在导出…），和 macOS 一样。
   确认框不用问号，标题说要做的事，确认按钮写动词。
4. **长一点的说明最多两句。** 每句单独一行（单独一个元素或数组的一项），句末不加标点，
   不插话。第一句说出了什么事，第二句说能怎么办；用户用不着的解释不写。
5. **列举用半角逗号加空格。** 页码写成 `1-3, 8`。输入框照样认 、，, 和空格。
6. **同一类文字用同一种结构。**
   - 按钮：动词，或动词 + 宾语（导出 PDF、打开目录、新建笔记）。
   - 设置行和权限：名词短语，不加说明（管理白板、设置白板、清空白板、导出白板）。
   - 状态：保持原样（已连接、未连接、同步中）。
7. **中文和拉丁字母、数字之间留一个空格**：导出 PDF、5 页、1920 × 1080 像素。
