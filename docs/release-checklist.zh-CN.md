# 发版前检查清单

将预发布版转为正式版之前，在真机上逐项完成本清单。

CI 只在 Linux 上的 Chromium 和 WebKit 中运行。Apple Pencil 输入、iPadOS Safari、iPad 外壳与打包后的 `.app` 只能在真机上验证。

## 0. 升级之前

- [ ] 在 Mac 上执行 `python tools/check_boards.py`，输出的最后一行应为「全部白板都能完整读出。」

> **警告**
> 如有白板会以只读白板打开，不要升级，先将输出发送给开发者。

## 1. Mac

### 升级

- [ ] 安装预发布版并首次打开。存储目录中出现 `backups/upgrade/<时间>_<旧版本>_to_<新版本>/`，其中包含 `boards/` 以及存在的 `index.json`（从 1.0.x 升级时）、`index.sqlite`、`space.json`、`spaces/`。
- [ ] 从 1.0.x 升级时：存储目录中出现 `index.sqlite` 与 `space.json`，`index.json` 改名为 `index.v1.json`；1.0.x 中应用建立的白板移入 `spaces/<应用名>/`，在白板库边栏「应用」中对应的一行里能以只读方式打开。
- [ ] 「关于白板」（菜单栏「白板」→「关于白板」）中显示新版本号，带 `-rc` 后缀。
- [ ] 原有白板全部存在，内容、文件夹与顺序均与升级前一致。打开其中若干块，均不出现只读提示。

### 书写与编辑

- [ ] 鼠标书写、撤销、重做正常。「清空白板」在清空前要求确认。
- [ ] 对象橡皮擦与像素橡皮擦均可擦除，撤销可恢复被擦除的笔画。
- [ ] 新建大白板与笔记。将 PDF 拖入窗口新建文档板，在 PDF 上书写并导出。
- [ ] 将一份多页的 PDF 拖入窗口：导入对话框显示每一页的缩略图。范围填 `2-3`，勾选「每页后面加一页空白」后导入：白板上是 4 页，依次是原件第 2 页、空白页、第 3 页、空白页。右键点按一页空白页 →「删除这一空白页」先确认再删除。导出 PDF：页面和白板上一样，剩下的空白页上有白板的背景底纹。缩略图一直是空的或页面不对时，发回截图和日志文件。
- [ ] 导出：选两页分别导出 PDF 和 PNG。保存对话框建议的文件名以 `.pdf` 或 `.zip` 结尾，保存的文件能在「预览」中打开。否则发回日志文件（菜单栏「白板」→「关于白板」→「日志文件」）和建议的文件名。
- [ ] 导出 → 调整：用触控板拖动页框、拖角缩放；双指平移时移动的是白板而不是页框。页框不跟手时发回录屏。
- [ ] 导出 → WBZ：保存对话框建议的文件名是 `<白板名>.wbz`。存到存储目录以外，然后在访达里双击这个文件：应用把它打开成一块内容相同的新白板。文件名不对或打不开时，发回日志文件和保存的 `.wbz`。

### 窗口

- [ ] 标题栏左边显示白板名称，名称下方是所在的文件夹。
- [ ] 标题栏：关闭、最小化、缩放三个按钮在顶栏左端，和顶栏里的按钮在同一条中线上，编辑界面和白板库都是。点一下顶栏或白板库的顶栏，窗口不会移动；拖动空白处窗口跟着顺滑移动；双击空白处窗口缩放。顶栏里每个按钮都能点，包括紧挨着窗口按钮的「白板库」。改变窗口大小、退出全屏之后，三个窗口按钮还在原位；全屏时顶栏左边不留空。窗口跳动、有按钮点不到或者窗口按钮位置不对时，发回录屏，以及日志文件中以 `titlebar` 开头的行。
- [ ] 缩放：点「放大」「缩小」以及用触控板捏合时，右下角的比例随之变化；点比例回到 `100%`。比例不变或与实际缩放不符时，发回截图。
- [ ] 菜单和面板：「更多」「颜色与粗细」「白板设置」「连接其他设备」打开后，点外面任何地方都能关上，这一下也照常点到底下的东西。哪个关不上，截图并说明是哪一个。
- [ ] 连接其他设备：打开「连接其他设备」，用 iPad 自带的相机扫描面板中的二维码，Safari 打开这块白板，地址与面板中显示的相同。点「在 iPad 上安装白板」后再扫，打开的是外壳安装页。扫不出或打开的地址不对时，发回面板的截图和 iPad 上打开的地址。
- [ ] iPad 打开白板时，Mac 窗口出现「iPad 已连接」，「连接其他设备」的图标变蓝，面板的「已连接」中列出 iPad。在 iPad 上关掉页面（或关闭 Wi-Fi）后，出现「iPad 已断开」，图标恢复原色。提示没出现、出现两次或图标颜色不变时，发回日志文件，并说明 iPad 是怎样断开的。
- [ ] 指针和动效：鼠标移到工具栏、标题栏的按钮、白板库的卡片和对话框的按钮上，都会出现灰底或者微微浮起；菜单和面板从按钮那里展开，关上时淡出，开头和结尾都不闪、不跳。按 Esc 能关掉导出对话框。哪里没反应、闪了或跳了，发回录屏。
- [ ] 白板库的设置：边栏最下面的「设置」显示二维码、地址、已连接的设备、权限开关和存储位置；在这里改的权限，白板设置面板里也跟着变，面板底部的「所有设置…」打开这一页。缺了哪一段或者改了不生效，发回截图。

### 白板库与设置

- [ ] 右键点按一块白板，菜单中有「打开」「重命名」「移到文件夹」「复制」「导出…」「移到回收站」；右键点按白板库的空白处，菜单中有「新建白板」「新建文件夹」「导入 PDF 或图片…」「以图标显示」「以列表显示」。菜单出现在指针处，不出现系统或网页自带的右键菜单。否则发回截图。
- [ ] 在 Mac 窗口（不是浏览器）的白板库中按 ⌘N 弹出新建白板的两个选项，按 ⇧⌘N 在边栏新建一个名称处于编辑状态的文件夹，按 ⌘I 打开文件选择框。任一快捷键没有反应或触发了别的动作时，说明是哪一个快捷键以及出现了什么。
- [ ] 把一块白板拖到边栏的文件夹上，它移入该文件夹；拖到「全部白板」上，它移出文件夹；拖到「回收站」上，它移到回收站。⌘ 单击选中两块后拖动其中一块，两块一起移动。拖不动或落到别处时，发回录屏。
- [ ] 排序方式选「手动排列」，在「全部白板」中拖动卡片调整顺序；关闭并重新打开应用后顺序不变。排序方式为「修改时间」时，拖动卡片不改变顺序。
- [ ] 回收站：在回收站中对一块白板选「恢复」，它回到原来的文件夹；对另一块选「永久删除」并确认，存储目录 `boards/` 中它的 `.wbz` 文件随之消失。「清空回收站」先请求确认。结果不符时，发回日志文件和回收站的截图。
- [ ] 复制：对一块大白板和一块文档板分别选「复制」，原白板之后出现「<名字> 副本」，打开后内容与原白板相同，文档板的副本显示 PDF 页面。结果不符时，发回截图和日志文件。
- [ ] 重命名白板和文件夹、新建文件夹以及搜索均正常。
- [ ] 在「白板设置」→「存储位置」中点「更改…」更换一次存储目录，再改回原目录，白板全部存在。
- [ ] 关闭窗口后重新打开，刚写入的内容全部存在。
- [ ] 日志文件 `~/Library/Logs/Whiteboard.log` 中每一行只出现一次。

### 打开方式

这些项目依赖打包后应用的 Info.plist 和访达，CI 无法检查。

- [ ] 在访达中，PDF 和 JPEG 文件的「打开方式」列出本应用，这两类文件的默认打开方式不变。
- [ ] 应用未运行时，用本应用打开一份 PDF，应用启动并新建文档板；多页的 PDF 先弹出导入对话框。
- [ ] 白板库显示某个文件夹时，用本应用打开一张图片，新白板位于该文件夹中。
- [ ] 双击 `backups/upgrade/` 中的 `.wbz`，导入为新白板，`backups/` 中的文件不变。

### 更新（Sparkle）

CI 会检查打包后的应用能加载 Sparkle、增量包能正确应用。真正装上更新只能在 Mac 上验证。

- [ ] 从 GitHub Pages 站点安装最新的 alpha 构建。「关于白板」显示的版本号以 `-alpha.<构建时间>` 结尾。
- [ ] 往 `dev` 合入任意一个改动，等 CI 通过。一小时内更新会在后台下载，不弹提示；退出并重新打开应用后，「关于白板」显示新的构建。
- [ ] 「检查更新」打开 Sparkle 的窗口，显示最新版本。
- [ ] 菜单栏：应用名显示「白板」，菜单全部是中文（关于白板、检查更新…、服务、隐藏白板、隐藏其他、全部显示、退出白板；编辑菜单的剪切、拷贝、粘贴、全选），应用名前面没有空格。「检查更新…」打开 Sparkle 的窗口；「关于白板」打开 macOS 标准的关于窗口，文字是中文：图标、「白板」、「版本 1.3.0 (alpha.…)」，下面是「更新日志」「日志文件」两个链接；「更新日志」在浏览器里打开发布页，「日志文件」在「控制台」中打开日志。哪一项还是英文、版本那一行没有构建时间或者链接点了没反应，截一张菜单或关于窗口的图发回来。
- [ ] 从 1.2.0 升级：原来的更新对话框提示这个正式版；装上之后，「检查更新」打开的是 Sparkle 的窗口。

任一项不通过时，请发回 `~/Library/Logs/Whiteboard.log` 中以 `Sparkle` 开头的行，以及 `/Applications/Whiteboard.app/Contents/MacOS/Whiteboard --check-updater` 的输出。

## 2. iPad

本节执行两遍：一遍在 iPad 外壳中，一遍从主屏图标打开。

### 外壳与工具栏

- [ ] 外壳：打开后不反复弹出「有新版本」。需要更新外壳时，安装的外壳与 Mac 端版本号相同。
- [ ] 外壳在 alpha 之间更新：Mac 装上一个改了外壳代码（`ipad/`）的 alpha 后，外壳回到前台时弹出「外壳有新版本」，点「更新」由 TrollStore 装上；只改了网页的 alpha 不弹。没有弹出时，在「设置」App 的外壳页面看「版本」，并发回 Mac 上 `http://<Mac 地址>/ipad/version` 的内容。
- [ ] 工具栏为笔具盘；此前关闭过笔具盘的 iPad 上同样为笔具盘。

### 白板库与外框

- [ ] 点按左上角的「白板库」打开白板库；点按一块白板直接打开它。
- [ ] 在白板库中用平常的速度点一下一块白板（不必特意快点），直接打开这块白板；白板库在这块白板出现时才关掉，中间不会先露出上一块白板。点了弹出菜单、或先看到上一块白板时，发回录屏。
- [ ] 在白板库中长按一块白板不动（半秒以上），松手后弹出菜单（「打开」「重命名」「移到文件夹」「复制」「导出…」「移到回收站」），白板没有被打开，也不出现放大镜、文字选择或系统菜单。长按后移动，白板被拎起，可以拖到边栏的文件夹或「回收站」上。长按边栏中的文件夹弹出「重命名」「在此新建白板」「删除文件夹」。菜单不出现、白板被打开或出现系统菜单时，发回录屏。
- [ ] 点白板库左上角的边栏按钮，边栏收起，再点一次显示。竖屏时边栏默认收起，在边栏中选一项后自动收起。边栏盖住内容或按钮点不到时，发回横屏和竖屏各一张截图。
- [ ] 点按按钮、菜单项或卡片并松手后，它不会一直保持高亮、像被按住一样。
- [ ] 手势：在文档板上长按一页弹出菜单、点空白处关掉，再双指张开（应放大）、单指往下拖（应平移，不缩放）。缩放方向反了或单指拖成了缩放时，发回录屏，并说明之前刚做过什么操作。
- [ ] 页码滑条：在几十页的文档板上滚一下，右边出现细滑块，停下后淡出；用手指按住滑块上下拖，页面跟着走、旁边显示页码，不会写出笔迹；松手停在那一页的顶上。贴着屏幕右边用 Pencil 写字（滑块没显示时）照常写得上。拖不动、写出笔迹或右边写不上字时，发回录屏。
- [ ] 在文档板上用手指按住一页不动：半秒后弹出有「在后面插入空白页」的菜单，不出现放大镜、文字选择或系统菜单，也没有画出笔迹。两指捏合不会弹出。笔具盘「…」菜单最上面有「在这一页后面插入空白页」，加在屏幕中间那一页后面。菜单不出现或出现系统菜单时，发回录屏。
- [ ] 右上角的连接状态：连着 Mac 时图标为蓝色，点按显示「已连接」和 Mac 的地址，没有彩色圆点；在 Mac 上退出应用后图标变灰，点按显示「未连接」；重新打开应用后恢复。外壳中另有一个小的「换一台 Mac」按钮，白板设置里不再重复出现。角上的按钮打开面板时背后没有圆底，按下时变淡。按平常的速度点开、关上、再点开面板，不会弹出诊断面板；快速连点三下才会。诊断面板误弹出时，说明当时点得有多快。

### 文字输入

CI 中的浏览器无法重现 iPadOS 上输入框无法输入文字一类的问题，以下各项只能在真机上检查。

- [ ] 白板库：搜索框可输入中文与英文并筛选出结果；长按白板选「重命名」后可输入名称；边栏中新建文件夹（「+」）与重命名文件夹的输入框均可输入。
- [ ] 在 iPad 上重命名白板、尚未完成输入时，在 Mac 上重命名另一块白板。iPad 的键盘不收起，已输入的文字不丢失。
- [ ] 重命名时 iOS 不自动更正，也不将首字母改为大写。
- [ ] 在边栏中新建文件夹时，名称输入框不被键盘遮挡；键盘收起后，界面与笔具盘位置正常。

### 嵌入的手写板

先将 `examples/apps/demo/` 复制到存储目录的 `apps/` 中。

- [ ] 在 iPad 外壳中打开 `/apps/demo/`。该页面没有诊断面板，但快速书写的笔画与在白板中一样流畅。
- [ ] 答案输入框可以输入文字，工具按钮可以使用。
- [ ] 在 Mac 上从白板库边栏的「应用」中打开「示例 第 1 题」，显示示例中写的笔画，下方有题图。
- [ ] 在 Mac 上把「首页」设为 `demo`。重新打开外壳后显示示例页面；其中的「白板」链接回到白板。最后改回「白板」。

### 主屏图标

- [ ] 导出：单张 PNG、PNG 压缩包和 PDF 都能保存（Safari 中为下载；外壳中弹出共享面板）。否则发回出现的界面截图。
- [ ] 导出 → 调整：手指可以拖动页框、拖角缩放，双指在白板上仍可平移缩放。点「清空」之后，在白板上用一根手指、用 Pencil（外壳里也试）拖动，都拖出一个新页框，不落笔。白板被拖走或落了笔时发回录屏。
- [ ] 导入文档时从「照片」选择图片（包括 HEIC），结果符合预期；不支持的格式显示提示。

### 书写

- [ ] Apple Pencil：压感与倾角生效，快速书写不断笔，笔画末端不出现鼓包，手掌放在屏幕上不留痕迹（手掌屏蔽）。
- [ ] 单指平移、双指缩放；打开手指书写后，单指可书写。
- [ ] 形状识别（笔具盘「更多」里的「形状识别」）：用 Pencil 画一条略弯的线，笔尖停住不动。约半秒后，笔还按着，这条线在两端都变直；之后移动 Pencil，终点跟着走。撤销一次，两端都回到手写的样子。稍一迟疑就抬笔、写完停住的字或弧线、开关关闭时，笔画都保持手写的样子。失败时发回这一笔的输入录像（docs/recording.zh-CN.md），并说明是变直得太早、太晚还是没有变直。
- [ ] 像素橡皮擦：笔身竖直时擦除宽度小，笔身放平时宽度大；同一次拖动中改变笔身角度，宽度随之逐渐变化，不需要抬笔。
- [ ] 尺子：点笔具盘里的尺子按钮。两指按在尺子上可以拖动和旋转尺子，画布不动，显示的角度跟着手指变化。两指按在尺子外面，照常平移和缩放画布。
- [ ] 尺子：一只手按住尺子，用 Pencil 沿尺边画线。画出的是贴着尺边的直线，放大画布后同样如此；离尺子几厘米起笔的笔画不会被吸到尺边上。Mac 上能看到这条线，看不到尺子。

尺子的任一项不通过时，请发回 iPad 的录屏，并说明页面是在 iPad 外壳中还是从主屏图标打开的。

### 同步

- [ ] 两端同时打开时，iPad 上写的内容立即出现在 Mac 上，Mac 上写的内容立即出现在 iPad 上。
- [ ] 断开 Wi-Fi 后书写几笔，再重新连接，这几笔同步到另一端且不重复。
- [ ] 在 Mac 上退出并重新打开应用，iPad 自动重新连接，内容不丢失。

## 3. 只读白板（可选）

本节检查只读提示本身。

- [ ] 复制一块白板的 `.wbz` 文件作为备份，然后用文本编辑器修改原文件中的若干字节。
- [ ] 打开这块白板：两端均弹出只读提示，落笔改为拖动画布。
- [ ] 在 Mac 上选择「仍然编辑」：`backups/locked/` 中出现原文件的副本，两端均可继续书写。
- [ ] 用备份恢复该文件。

## 4. 发布正式版

全部检查通过后，在 `stable` 分支上推送不带后缀的 tag（例如 `v1.0.0`）。

```bash
git tag v1.0.0 && git push origin v1.0.0
```

| Tag | 发布为 | 应用内更新是否提示 |
| --- | --- | --- |
| `v1.0.0` | 正式版 | 是：Sparkle 的 `stable` 通道；旧的更新方式通过 `releases/latest` |
| `v1.0.0-rc.1`（含连字符） | 预发布版 | 只推给 `alpha` 通道的 Mac |

- CI（`.github/workflows/ci.yml`）跑完全部 job，把 Sparkle 更新发布到 GitHub Pages，再将 `.zip` 与 `.ipa` 发布到 GitHub Release。
- 带 Sparkle 的构建读取 GitHub Pages 上的 `appcast.xml`；不带的构建（1.2.0 及更早）读取 `releases/latest`，其中不包括预发布版。
- Release 说明取自 `CHANGELOG.md`（只有英文版，写法见 `docs/changelog-style.md`）中该版本的一节（`packaging/release_notes.py`），更新对话框显示的即为这段说明。预发布版没有单独一节时，使用对应正式版的一节；两者均不存在时，由 GitHub 自动生成说明。
