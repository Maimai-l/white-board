# 指针反馈和动效

界面照 macOS / iPadOS 的控件做，反馈也照它们：指上去就知道能点，按下去有回应，
东西打开时从按钮那里长出来，关上时淡出而不是一下子没了。

## 每种动作一条曲线、一个时长

取值都在 `app.css` 末尾「动效」一节的变量里，别处不写死数字。

| 动作 | 变量 | 取值 | 做什么 |
| --- | --- | --- | --- |
| 悬停 | `--t-hover` | 120 ms，`--ease-out` | 底色、颜色、明暗淡入淡出 |
| 按下 | `--t-press` | 90 ms | 再深一点；图标按钮缩到 0.92 |
| 打开 | `--t-enter` | 180 ms，`--ease-out` | 透明度在前 40% 走完，其余时间缩放 0.96→1，从按钮的方向长出来 |
| 关上 | `--t-leave` | 140 ms，`--ease-in` | 淡出并缩到 0.97 |

- 菜单从按钮那一角长出来：在按钮下面开就是左上角，在上面开（工具栏）就是左下角。
  子菜单不放进场动画，和 macOS 一样指到就出来。
- 顶栏按钮下面的面板、新建白板面板从右上角往下展开；颜色与粗细从工具栏往上长。
- 对话框和暗底：暗底只淡背景色，不淡 `opacity`（`opacity` 小于 1 会让里面的磨砂
  只采样到暗底，弹窗自己先黑一下）；里面的对话框自己缩着淡入淡出。
- 位移和缩放用 `translate` / `scale` 属性，不用 `transform`：提示条靠 `transform`
  居中，动画改 `transform` 的话第一帧会横着跳。

## 悬停和按下

- 所有 `:hover` 都在 `@media (hover: hover)` 里：iPad 上点过的元素会一直留着
  `:hover`，像被按住了一样。触摸设备只有按下的反馈。
- 有底色的按钮（灰底、蓝底、红底）悬停时用 `--hover-filter` 压暗一点，按下用
  `--press-filter` 再暗；深色模式里这两个是提亮。一套规则管所有颜色的按钮。
- 透明的图标按钮（顶栏、工具栏、缩放）悬停是一层 `--fill` 灰底，按下是更深的
  `--press-fill`，图标缩一点。当前工具悬停时强调色的底再深一点。
- 文字链接悬停有下划线，按下变淡。分段控件没选中的那段悬停变深。
- 卡片和样张悬停浮起来一点；菜单项悬停是整行强调色，不放过渡，和 macOS 一样。

## 关上：`motion.js` 的 `leave()`

关菜单、面板、弹窗、提示条、白板库都走 `leave(node)`：节点加上 `.leaving`，
同时 `inert`，140 ms 后再 `remove()`。

- 退场中的节点不接收点击和键盘：淡出的那一下底下照样能点，紧接着再开一个也没问题。
- 状态（`this.panel`、`this.popover` 这些）在调用 `leave()` 时就清掉，代码里不会
  把正在退场的那个当成开着的。
- 白板库整个重画（列表刷新）不走 `leave()`，否则别处一改名这边就闪一下。

## 减弱动态效果

系统设置了「减弱动态效果」时，进场和退场都不放，悬停的变化直接到位，`leave()`
直接拿掉节点。

## 测试

`tests/e2e/test_motion.py`：

- 在 Mac 窗口的每个界面里，把每个看得见、能点的控件指一遍，比较悬停前后的计算样式，
  没有变化的列出来。新加的控件没有悬停反馈，这个测试就是红的。
- 菜单、面板、颜色与粗细、导出、确认框、白板库：打开时有 CSS 动画；关上时先进入
  退场（有动画、`pointer-events: none`），至少 80 ms 后才从页面上拿掉。
- 减弱动态效果时一开一关就是直接加上、直接拿掉。

别的测试里，关掉之后要确认某个东西没了，用 `support.gone()` 等它消失；找开着的菜单
或白板库用 `support.MENU` / `support.LIBRARY`，它们跳过正在退场的那一个。
`test_ui_states.py` 截图前等所有动画停下。
