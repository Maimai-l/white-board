# 导出第二版：整张导出、从零画页框、从上往下分页、导出白板文件

状态：进行中　　来源：需求池（2026-11-20 用户对第一版导出的反馈）

## 为什么

用户原话：「打的这个框算法我觉得问题有点多，你根本没有给导出完整大图片的功能，还有没办法从 0 手动打框，
你打的框问题就是分的太细太小，我觉得目标是从上往下，自动识别出一个范围，关键问题是我现在没法导出一个白板
raw file，给你用来测试。」

第一版（001）的大白板分页先把笔画聚成组、每组按 1:1 放进一张纸：写得分散的白板会切出很多张小页，
而且没有「整块白板一张图」的出口。agent 手里没有用户真实的白板，分页算法只拿合成的数据测过。

## 要做什么

1. **导出白板文件（.wbz）**：导出对话框里能直接下载当前白板的原始文件，用户发给 agent 当测试数据。
   在这之前，用户按交付说明里的步骤从存储目录取文件。
2. **整张导出**：不分页，整块白板（所有墨迹的范围）出一张 PNG 或一页 PDF。
3. **从上往下自动分页**：大白板也按「一列往下读」来分：先识别墨迹的左右范围作为页宽，等比放进纸宽，
   再从上往下按纸张长度切，切口落在两行之间的空白里（和笔记的分法一致）。
4. **从零画页框**：调整视图里能清空所有页框，在白板上拖出新的页框。

先拿用户发来的真实白板，把第一版和第 3 条的分法并排画出来给用户看，对齐之后再定第 3、4 条的细节和设计稿。

## 验收：黑盒测试

- 导出对话框选「白板文件」，下载到的 .wbz 拖回应用能打开成同样的白板。
- 选「整张」，PNG 的内容范围包住所有墨迹，PDF 只有一页。
- 用用户的真实白板（脱敏后放进 `tests/fixtures/`，需用户同意）：自动分页的页数和每页范围在用户认可的结果上固定成测试。
- 调整视图里清空页框、拖出一个新框、完成，导出的页正好是这个框。
