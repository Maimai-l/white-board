# 尺子（iPad）

状态：进行中　　来源：需求池

## 为什么

画图、做笔记时需要画准确的直线和角度。

## 要做什么

已对齐（2026-11-19）：

- 只在 iPad 上有，放在笔具盘里。
- 两指拖动和旋转尺子，显示当前角度。
- 笔贴着尺边写，画出来的就是沿尺边的直线。
- 尺子本身不同步，只是本机的辅助工具；画出的线照常同步。

## 验收：黑盒测试

- 打开尺子后，两指旋转到 30°，显示的角度为 30°。
- 笔沿尺边画一笔：存下来的笔画上所有点到尺边的距离不超过 1 个白板单位；Mac 端看到同一条线。
- Mac 页面上看不到尺子。

## 不做

- Mac 上的尺子、尺子位置同步。

## 进展

- 2026-11-19 `claude/ruler`：行为做完，外观按设计稿（浅色半透明尺身、两侧刻度、白色角度标签、
  笔具盘里橡皮右边立着的尺子）。外观只在 `whiteboard/web/static/js/ruler-view.js`
  和 `css/app.css` 的「尺子」一节；几何在 inksync 的 `ruler.js`，手指和笔的分派在
  `input-ruler.js`。验收测试在 `tests/e2e/test_ruler.py`，几何的白盒测试在
  `tests/js/ruler.test.mjs`。
- 自己定的规则：尺子固定在屏幕上，不随画布平移缩放；长度不设边；角度显示 0–90°
  （和水平线的夹角），45° 的整数倍 2° 以内吸附；Pencil 在尺身上或离尺边 24 pt 以内
  起笔就贴边，笔画的点全部投影到尺边所在的直线上；一指拖尺子，两指拖动加旋转；
  第一指在尺子上、第二指在外面时算捏合画布。显示的角度范围和吸附角度凭对 iPad 的
  印象定的，真机核对写进了发版检查表。
