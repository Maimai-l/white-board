# 尺子（iPad）

状态：待办　　来源：需求池

## 为什么

画图、做笔记时需要画准确的直线和角度。

## 要做什么

已对齐（2026-11-19）：

- 只在 iPad 上有，放在笔具盘里。
- 两指拖动和旋转尺子，显示当前角度。
- 笔贴着尺边写，画出来的就是沿尺边的直线。
- 尺子本身不同步，只是本机的辅助工具；画出的线照常同步。

## 验收：黑盒测试

- 打开尺子后，两指旋转到 30°，显示的角度为 30°。
- 笔沿尺边画一笔：存下来的笔画上所有点到尺边的距离不超过 1 个白板单位；Mac 端看到同一条线。
- Mac 页面上看不到尺子。

## 不做

- Mac 上的尺子、尺子位置同步。
