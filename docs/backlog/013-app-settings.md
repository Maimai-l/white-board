# 白板库左下角的设置

状态：待确认设计稿　　来源：用户直接反馈（2026-11-22）

## 为什么

用户反馈：在白板库里有点手足无措，检查连接和其他设置还得先打开一块白板，再点白板设置，很奇怪。
现在「白板设置」面板里混着两类东西：「背景」只管这一块白板；「iPad 可以」「存储位置」「iPad 首页」
和「连接 iPad」是整个应用的设置。

## 要做什么（已和用户对齐的决定写在这里）

- 用户提出：白板库左下角加一个设置入口。
- 用户指出：局域网里任何设备的浏览器都能打开白板，不只是 iPad；界面上管所有设备的地方不该叫 iPad。
- 设计稿（待用户确认）：https://claude.ai/artifact/GDtVPy88FDhxXV8fRyxNtc
  - 边栏最下面「回收站」下面加「设置」，选中后右边显示设置：连接其他设备（二维码、地址、已连接的设备）、
    其他设备可以（四个权限开关）、存储位置、首页（装了应用时）。
  - 编辑界面的「白板设置」只剩背景，下面一个「更多设置…」打开白板库的设置。
