# 白板库左下角的设置

状态：进行中　　来源：用户直接反馈（2026-11-22）

## 为什么

用户反馈：在白板库里有点手足无措，检查连接和其他设置还得先打开一块白板，再点白板设置，很奇怪。
现在「白板设置」面板里混着两类东西：「背景」只管这一块白板；「iPad 可以」「存储位置」「iPad 首页」
和「连接 iPad」是整个应用的设置。

## 要做什么（已和用户对齐的决定写在这里）

- 用户提出：白板库左下角加一个设置入口。
- 用户指出：局域网里任何设备的浏览器都能打开白板，不只是 iPad；界面上管所有设备的地方不该叫 iPad。
- 用户指出：总设置能设置了不代表白板设置里就要删掉这些设置，类比 iPhone 的控制中心和系统设置。
- 设计稿（用户已确认）：https://claude.ai/artifact/GDtVPy88FDhxXV8fRyxNtc
  - 边栏最下面「回收站」下面加「设置」，选中后右边显示设置：连接其他设备（二维码、地址、已连接的设备）、
    其他设备可以（四个权限开关）、存储位置、首页（装了应用时）。
  - 编辑界面的「白板设置」照旧（背景、其他设备可以、存储位置、首页），底部「所有设置…」打开白板库的设置。
  - 别的设备上，设置页显示连接：连的是哪台 Mac，外壳里有「换一台 Mac」。

## 验收：黑盒测试

- tests/e2e/test_library_settings.py：边栏最下面是设置；Mac 上设置页的几段、二维码、改权限；白板设置面板保留开关并能进到设置页；
  界面上不再写连接 iPad、iPad 可以；平板和 iPad 外壳上的设置页。
- tests/e2e/test_ui_states.py：两种窗口尺寸下设置页的截图和布局检查。
