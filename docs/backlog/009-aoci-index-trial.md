# AOCI-CODE 索引试验

状态：暂缓　　来源：流程改进

## 为什么

每个云端会话都从零认识项目。AOCI-CODE（github.com/aoci-spec/aoci-code）给每个文件写一行索引，
会话开始读一次就有全局认识。项目约 4.5 万行、170 个文件，在它建议的规模内。

## 要做什么

- 在环境的启动脚本里安装 aoci，固定路径；在工作分支上建索引。
- 对比接入前后：新会话从开始到第一次改对代码的时间和 token。省得明显就保留，否则撤掉。

## 注意

- 当前版本 v0.2.0-rc2，许可证 FSL-1.1-MIT。
- 它写的是 AGENTS.md，CLAUDE.md 里要引用。
