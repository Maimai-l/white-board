# Mac 窗口：红绿灯和顶栏一行，点顶栏窗口不再往下跳

状态：进行中　　来源：用户直接反馈（2026-11-22）

## 为什么

- 用户反馈：在白板库里点顶部那一条，窗口突然往下移动一点。原因是顶栏和白板库顶栏是
  pywebview 的拖动区域（`.pywebview-drag-region`），它用 JS 按「鼠标的屏幕坐标减去鼠标在网页里的坐标」
  放窗口，默认网页从窗口最顶上开始；我们的窗口带系统标题栏（约 28 px），网页在它下面，
  鼠标一动窗口就往下挪一个标题栏的高度。
- 用户给了参考（「用 pywebview 模仿 macOS 原生窗口：参考手册」）：红绿灯和工具栏在同一行。

## 要做什么（已和用户对齐的决定写在这里）

- 窗口用 `frameless=True`，网页铺满窗口，顶栏（52 px）就是标题栏。网页和窗口同一个原点，
  拖动的算法就对了。
- 红绿灯放出来，摆在顶栏左边、垂直居中，离左边 20（whiteboard/titlebar.py）；改变大小、退出全屏后重新摆。
  标题栏那层只盖到绿灯右边，不挡顶栏里的按钮。
- 顶栏只有空白处能拖（`DRAG_REGION_DIRECT_TARGET_ONLY`），标题文字让点击穿过去；双击空白处按系统设置缩放。
- 白板库：边栏顶上 52 高的一条放红绿灯，右边顶栏 52 高，同一条中线。
- 全屏时红绿灯由系统收起，页面不再给它留位置（`data-window="full"`）。

## 验收：黑盒测试

- tests/e2e/test_window.py：红绿灯那块空着且是拖动区域、顶栏 52 高、第一个按钮在绿灯右边同一条中线、
  标题不挡拖动、白板库对齐、双击空白处放大而双击按钮不会、全屏收回空白、浏览器里不留空。
- tests/test_titlebar.py：红绿灯的几何、全屏不动、双击跟随系统设置、主窗口没有系统标题栏。
- 真机：发版检查表「窗口」一节的标题栏那一项。

## 不做

- 侧边栏半透明材质（vibrancy）：参考手册里标着未验证，这一轮不碰。
