# 前端重新设计：白板库、编辑界面、面板

状态：进行中　　来源：用户的设计稿（[白板库 重新设计](https://claude.ai/artifact/7AUeyAuZiefn3rM8ejQ6e8)）

## 为什么

用户重新设计了整个前端：白板库改成访达 / 备忘录那样的边栏加格子，编辑界面换成 Mac 的磨砂标题栏，
设置、连接 iPad、关于改成从按钮弹出的面板，导出对话框和速写页跟着统一。用户要求先实现，遇到和现有
功能冲突的地方按设计师的思路自己定，回来看成果。

## 要做什么（已和用户对齐的决定写在这里）

- 白板库：边栏（最近按今天 / 本周 / 更早分段、全部白板、文件夹、应用、回收站），图标和列表两种显示，
  排序（修改时间、名称、手动排列），搜索，新建白板（向下延伸 / 四向延伸），右键和长按菜单（打开、重命名、
  移到文件夹、复制、导出、移到回收站；回收站里恢复、永久删除），空白处的菜单和 ⌘N / ⇧⌘N / ⌘I 快捷键，
  ⌘ 单击多选，卡片拖到边栏的文件夹、全部白板、回收站上，拖文件进来导入。
- 回收站：删除改成移进回收站，30 天后自动永久删除（服务端）。
- 复制白板（服务端）。
- 编辑界面（Mac）：顶栏放白板库、白板名字和文件夹、连接 iPad、导出、白板设置；底部工具栏是四件工具、
  颜色与粗细、撤销重做、更多；右下角缩放带百分比，点百分比回到 100%。
- 面板：白板设置（背景、iPad 可以、存储位置）、连接 iPad（二维码、地址和拷贝、已连接的设备、安装外壳）、
  关于（小窗口）。iPad 连上 / 断开时 Mac 上弹一条提示（服务端发 devices）。
- iPad：左上角返回白板库，右上角连接状态、导出、设置。
- 导出对话框：左边一栏是页，每页下沿一颗勾选胶囊；页面多一项所选的页。
- 速写页：底栏状态带文字，拷贝为图片。

和设计稿不一样的地方（设计师会怎么处理）：

| 设计稿 | 做法 | 原因 |
| --- | --- | --- |
| iPad 编辑界面底部的选笔 | 用现有的 PencilKit 笔具盘 | 用户确认：那个是打磨过的 |
| 在新窗口中打开、共享 | 不做 | 所有设备跟着同一块当前白板，第二个窗口只会显示同一块；网页里没有系统的共享面板，导出已经覆盖 |
| 把文件拖到卡片上添加到此白板、拖进白板插入图片 | 拖进来的文件一律新建白板 | 白板里只有笔迹，没有图片对象；文档板是一份原件当底 |
| 粗细三档 | 保留五档，画成设计稿里的横线 | 和笔具盘的五档对应，每支笔记的是档位，改成三档会把已有设置挪位 |
| 七种颜色 | 设计稿的七种再加黄色 | 荧光笔默认黄色 |
| 工具栏移到左侧 | 做了，原来的移到上边改成左边 | Mac 顶上是标题栏，工具栏不能再往上放 |
| 关于没有入口 | 放在工具栏的更多里（只在 Mac 窗口） | pywebview 窗口没有应用菜单 |
| 左上角的状态点去掉了 | 连接状态落在连接按钮上；连点三下打开诊断面板也挪过去 | 设计稿里连接按钮的颜色就是状态 |
| 权限名修改设置 | 用设置白板 | docs/ui-text.md 定的名字 |
| 导出“笔记”这样的标题、页码：1/7 | 导出加白板名、1 / 7 | docs/ui-text.md 不用全角引号和冒号 |
| 红绿灯画在顶栏里 | 暂时保留系统标题栏 | 透明标题栏下顶栏按钮能不能点只能在真机上确认，下一轮做 |
| 拖动排序 | 排序方式选手动排列时才能拖 | 按时间、名字排的时候拖动没有意义 |

## 验收：黑盒测试

- tests/e2e/test_gallery.py：白板库的每一项操作（Mac 鼠标、iPad 手指）。
- tests/e2e/test_chrome.py：顶栏、更多菜单、缩放百分比、设置和连接面板、关于、iPad 连上的提示。
- tests/e2e/test_export_dialog*.py：所选的页。
- 服务端：tests/test_hub.py、test_store.py、test_server.py（回收站、复制、devices、二维码）。

## 不做

- 新窗口、共享、往白板里插图片（见上表）。
- iPad 白板库的选择模式（设计稿右上角的选择按钮）：长按菜单已经覆盖单块白板的操作，下一轮再看要不要多选。
