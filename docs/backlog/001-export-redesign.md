# 导出重做：清晰、自动分页、选页、打印式对话框

状态：待办　　来源：需求池（两条合并：「无限白板导出 PNG 模糊……」和「导出 PDF 时只导出选中的页面」）

## 为什么

- 无限白板导出的 PNG 很模糊：`packages/inksync/inksync/web/exporter.js` 把导出图的长边限制在
  `MAX_EXPORT_PIXELS = 4096`，内容铺得越开，每个白板单位分到的像素越少。
- 不能只导出一部分，也不能只把某几页批注发给别人。

## 要做什么

已对齐（2026-11-19）：

- 一个导出对话框，布局参考打印界面：左边各页缩略图；可以选全部、当前页、范围或逐页点选；
  右边选格式（PDF、PNG 压缩包、单张 PNG）和清晰度。
- 无限白板自动分页：先把相近的笔画聚成组，每组放进一张 A4（横竖自动），组太大时再按网格切；
  导出前可以在预览里调整页框。分页后每页按完整清晰度输出，这本身解决模糊。
- 文档板用原件的页；笔记板按纸张长度切页。
- 先出设计稿给用户确认，再写代码（界面改动的规则见 CLAUDE.md）。

## 验收：黑盒测试

- 一块笔画分散的无限白板，导出 PDF 后每页里的笔画宽度（像素）和在 1:1 缩放下画出来的一致，不再被缩小。
- 选第 2、4 页导出，PDF 只有这两页，各自带着自己的墨迹。
- 自动分页不把一组相近的笔画切到两页（准备一组离得很近的笔画和一组离得很远的笔画）。
- PNG 压缩包里的文件数等于选中的页数，文件名按页序。

## 不做

- 这一版不做自定义纸张尺寸以外的版式（页眉、页码）。
