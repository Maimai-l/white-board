# 导出重做：清晰、自动分页、选页、打印式对话框

状态：完成　　来源：需求池（两条合并：「无限白板导出 PNG 模糊……」和「导出 PDF 时只导出选中的页面」）

## 为什么

- 无限白板导出的 PNG 很模糊：`packages/inksync/inksync/web/exporter.js` 把导出图的长边限制在
  `MAX_EXPORT_PIXELS = 4096`，内容铺得越开，每个白板单位分到的像素越少。
- 不能只导出一部分，也不能只把某几页批注发给别人。

## 要做什么

已对齐（2026-11-19）：

- 一个导出对话框，布局参考打印界面：左边各页缩略图；可以选全部、当前页、范围或逐页点选；
  右边选格式（PDF、PNG 压缩包、单张 PNG）和清晰度。
- 无限白板自动分页：先把相近的笔画聚成组，每组放进一张 A4（横竖自动），组太大时再按网格切；
  导出前可以在预览里调整页框。分页后每页按完整清晰度输出，这本身解决模糊。
- 文档板用原件的页；笔记板按纸张长度切页。
- 先出设计稿给用户确认，再写代码（界面改动的规则见 CLAUDE.md）。

## 验收：黑盒测试

- 一块笔画分散的无限白板，导出 PDF 后每页里的笔画宽度（像素）和在 1:1 缩放下画出来的一致，不再被缩小。
- 选第 2、4 页导出，PDF 只有这两页，各自带着自己的墨迹。
- 自动分页不把一组相近的笔画切到两页（准备一组离得很近的笔画和一组离得很远的笔画）。
- PNG 压缩包里的文件数等于选中的页数，文件名按页序。

## 不做

- 这一版不做自定义纸张尺寸以外的版式（页眉、页码）。

## 进展

- 2026-11-19 引擎（分支 `claude/export-engine`）：服务端分页与导出
  （`whiteboard/pagination.py`、`whiteboard/export.py`，`POST /api/export/{board}`、
  `GET /api/export/{board}/pages`，见 docs/protocol.zh-CN.md「分页导出」）；PDF 内容流压缩
  从 zlib 9 级改为 6 级，文档板导出快了约三倍。验收的四条黑盒测试在 `tests/test_export.py`。
- 2026-11-19 对话框（同一分支）：按确认过的设计稿做了导出对话框和调整页框视图
  （`whiteboard/web/static/js/ui-export.js`），Mac 窗口走原生保存对话框（`app.py` 的 `export_doc`）。
  黑盒测试在 `tests/e2e/test_export_dialog.py`。
- 和设计稿不同的两处：页框里面不加白色蒙层（蒙层会把框里的字盖淡，调整时看不清内容），
  只在页框以外蒙一层；文档板不显示「纸张」一行（原件的页就是纸，选了也不起作用）。
- 真机上要看的（Mac 触控板拖页框、iPad 外壳保存 PDF / 压缩包）写进了发版检查表。
- 遗留：自动分页时两组的页框可能互相重叠（框里不会多出别组的墨迹）；非文档板的图片层
  （1.0.1 的底图）服务端导出不画。合入 dev 后在这里补上合并的提交。
