# 形状识别（第一版：直线）

状态：完成　　来源：需求池（「划线自动停留变直」）

## 为什么

画直线、划重点时手写的线不直，笔记不好看。

## 要做什么

已对齐（2026-11-19）：

- 一笔写完后笔尖停住约半秒，这一笔变成两端点之间的直线。
- 设置里有开关（「形状识别」）。
- 两台设备同步的是变直之后的笔画；撤销一次回到手写的那一笔。
- 圆、矩形、三角形、箭头另列需求，这一版不做。

## 验收：黑盒测试

- 在 iPad 页面上画一条略弯的线并停住 0.6 s：两端都看到一条直线，端点和手写起止点一致。
- 停顿不到半秒就抬笔：笔画保持手写的样子。
- 开关关闭时停住也不变直。
- 变直后撤销：回到手写的笔画，另一端同步回去。

## 不做

- 识别直线以外的形状。
