# 导入 PDF 时选页、文档白板里加空白页

状态：进行中　　来源：用户直接反馈（2026-11-22）

## 为什么

用户导入几百页的教材，实际只想批注其中一段（比如第 3 到 15 页）；批注写不下时需要一页空白接着写。

## 要做什么（已和用户对齐的决定写在这里）

- 用户提出：导入时弹出对话框，可以只选要编辑的页（例如 3-15）；导入后（PDF 或图片）可以自己加空白页。
- 设计稿（待用户确认）：https://claude.ai/artifact/PczLaU95SikxCjZPbQx8Lh
  - 导入对话框沿用导出对话框的样子：左边一栏页面缩略图可以点选，右边是页面（全部 / 范围 / 所选的页）
    和「每页后面加一页空白」，按钮写「导入 13 页」。范围的写法和导出一样（1-3, 8）。
  - 文档白板里右键（iPad 上长按）一页：在后面 / 前面插入空白页；空白页可以删除，原件的页不能删。
    空白页和相邻的页一样大，底纹跟着白板的背景设置。
- 用户确认：PDF 多于 1 页就弹导入对话框，默认全部；单张图片直接建板。
- iPad 上加空白页（设计稿后两张）：手指长按一页弹出菜单（行高 44 pt，手指默认不写字，不和书写冲突）；
  笔具盘的「…」菜单最上面加「在这一页后面插入空白页」（屏幕中间那一页），这是看得见的入口。

## 验收：黑盒测试

`tests/e2e/test_doc_pages.py`：

- 拖入 6 页的 PDF 弹出导入对话框，6 张缩略图；范围填 3-5、勾每页后面加空白，导入后白板的页是原件 3、空白、4、空白、5、空白。
- 导入对话框按 Esc 取消，不建白板。单页 PDF 不弹对话框。
- 右键一页：原件的页只有插入两项；插入后有背景设置；右键空白页删除，先确认。
- 更多菜单的「在这一页后面插入空白页」加在屏幕中间那一页后面。
- 平板上手指按住一页弹出页的菜单；iPad 笔具盘「…」里的那一项加空白页。
- `tests/test_open_files.py`：从访达打开多页 PDF 弹导入对话框。

白盒：`tests/test_doc_pages.py`（笔迹和擦除遮罩跟着页移动、空隙里的笔迹归最近的页、只删空白页、400 页上限），
`tests/test_server.py`（暂存、建板、权限、加删页后保存再打开），`tests/test_export.py`（有空白页的文档板导出）。

- 调整页的顺序。
