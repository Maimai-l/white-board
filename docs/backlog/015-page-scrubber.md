# 文档白板右侧的页码滑条（快速翻页）

状态：待确认设计稿　　来源：需求池（2026-11-25）

## 为什么

用户在 iPad 和 Mac 上读几百页的 PDF，要翻到后面某一页只能一路滚，太慢。

## 要做什么（已和用户对齐的决定写在这里）

- 需求池原文：iPad 和 Mac 端加上快速翻页功能，尤其是阅读 PDF 的时候。
- 用户在几种方式（右侧页码滑条、缩略图边栏、页码跳转、上一页 / 下一页）里选了右侧页码滑条。
- 设计稿（待用户确认）：https://claude.ai/artifact/BRrF6CRZroDKDmAknhvo9o
  - 文档白板多于一页时，屏幕右边有一条页码滑条，平时看不到；滚动时出现细滑块，停下 1.5 秒后淡出。
  - 指针移到右边、或手指按住滑块：出现轨道，滑块变粗；上下拖，页面跟着走，旁边显示「12 / 300」；点轨道直接跳到那一页。
  - iPad 上滑块的可点范围 44 pt 宽；Pencil 和手指都能拖，拖滑块时不写字。
