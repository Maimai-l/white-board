# 文档白板右侧的页码滑条（快速翻页）

状态：完成　　来源：需求池（2026-11-25）

## 为什么

用户在 iPad 和 Mac 上读几百页的 PDF，要翻到后面某一页只能一路滚，太慢。

## 要做什么（已和用户对齐的决定写在这里）

- 需求池原文：iPad 和 Mac 端加上快速翻页功能，尤其是阅读 PDF 的时候。
- 用户在几种方式（右侧页码滑条、缩略图边栏、页码跳转、上一页 / 下一页）里选了右侧页码滑条。
- 设计稿（用户已确认）：https://claude.ai/artifact/BRrF6CRZroDKDmAknhvo9o
  - 文档白板多于一页时，屏幕右边有一条页码滑条，平时看不到；滚动时出现细滑块，停下 1.5 秒后淡出。
  - 指针移到右边、或手指按住滑块：出现轨道，滑块变粗；上下拖，页面跟着走，旁边显示「12 / 300」；点轨道直接跳到那一页。
  - iPad 上滑块的可点范围 44 pt 宽；只有手指能拖，拖滑块时不写字。Pencil 落在滑块上照常写字（2026-11-26 用户反馈 Pencil 误触后改）。
  - 拖的时候页面实时跟着走；一路经过的页先不加载图像，停下再加载（agent 定的，用户可以改成松手才跳）。

## 验收：黑盒测试

`tests/e2e/test_page_scrubber.py`：

- 滚动后出现细滑块，停下后淡出。
- Mac 上指针移到右边出现轨道；拖滑块时气泡显示「N / 30」、屏幕中间就是那一页，松手停在那一页顶上。
- 点轨道底部跳到最后一页。
- iPad 上手指滚一下再拖滑块（真触摸事件）：翻到后面，没有写出笔迹。
- 滑块没显示时，贴着右边用 Pencil 写字照常写上。
- 只有多于一页的文档板才有滑条。

`tests/e2e/test_ui_states.py`：两种窗口尺寸下指着和拖动时的截图。

## 不做

- 缩略图边栏、页码跳转、上一页 / 下一页按钮（用户这次没选）。

## 进展

- 2026-11-25：画了设计稿，用户确认。实现：inksync 加 `view` 事件和 `ImageLayers.hold`，白板应用加 page-scrubber.js。
- 2026-11-25：合进 dev（PR #35），随 alpha 1.3.0-alpha.20261125.063844 发出。
- 2026-11-26：用户反馈 Pencil 会误触滑条。改成只有手指和鼠标拖滑块，Pencil 落在滑块上交给白板照常写字。
