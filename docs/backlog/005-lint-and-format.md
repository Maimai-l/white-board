# 统一格式化（ruff format）

状态：待办　　来源：流程改进

## 为什么

现在 CI 只开了 ruff 的错误类规则（`E9,F63,F7,F82`，008 之后加了吞掉异常的 `S110,BLE001`）。完整规则下有 967 条问题，其中 926 条是行太长；
没有统一格式，评审时会在格式上来回。

## 要做什么

- 一个单独的提交做 `ruff format`（只改格式），再在 checks 里加 `ruff format --check`。
- 逐步打开其他规则，每开一条先把现有代码改干净。

## 验收

- `make checks` 包含格式检查并通过。
